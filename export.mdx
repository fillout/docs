## Export Zite database

From your dashboard, hover over a database and click <Icon icon="ellipsis" /> followed by `Export database`.

  src="/images/Screenshot2026-03-13at4.24.26PM.png"

A JSON file will automatically be added to your device's downloads folder.

## Move databases

If you need to simply transfer a database into a different workspace, drag and drop them there. More info here.

## Import database

You can also import an external database or spreadsheet into your Zite database. Check out the guide [here](https://www.fillout.com/help/database/import-data).
