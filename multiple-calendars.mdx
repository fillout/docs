## Overview

You can connect multiple Google or Microsoft calendars in a single [organization](https://www.fillout.com/help/organizations). This is useful for teams where each member has their own calendar. Fillout can check availability across connected calendars.

Each scheduling page can only be linked to one calendar. However, you can still add other team members as hosts, such as when using [round-robin scheduling](https://www.fillout.com/help/round-robin), so Fillout can check their availability and assign bookings accordingly.
