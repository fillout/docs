## Overview

When your app is [shared to the web](/zite/access/share-to-web), you can require users to sign in before accessing it. Zite handles authentication for you — no custom login code needed.

## Set up authentication

<Steps>
  <Step title="Share your app to the web">
    If you haven't already, enable **Share to web** in **Settings** > **Access**. See [Share to web](/zite/access/share-to-web).
  </Step>
  <Step title="Add login">
    Type **"Add user login"** in your Zite chat, or click **+** and select `Add login`.

    <img
      src="/images/Screenshot2025-12-16at2.43.01PM.png"
      alt="Add login option"
      style={{ width:"43%" }}
    />
  </Step>
  <Step title="Configure sign-in methods">
    In **Settings** > **Access**, under **Sign-in method**, choose which methods to enable:

    - **Magic link** — Users receive a sign-in link via email (valid for 10 minutes)
    - **Google Sign-in** — Users sign in with their Google account
    - **SSO** — Users authenticate through your organization's identity provider. [Learn more](/zite/access/sso).

    Magic link and Google are enabled by default. At least one method must be enabled.
  </Step>
  <Step title="Choose who can sign up">
    Under **Who can sign up?**, select one of:

    | Setting | Description |
    |---------|-------------|
    | **Invite only** (default) | Only users you explicitly add can sign in |
    | **Anyone** | Anyone who visits your app can create an account |
    | **Only allowed domains** | Only users from specific email domains (e.g., `example.com`) can sign up |
  </Step>
</Steps>

## Manage users

When your app has authentication enabled, the **Users** tab shows external users who have signed in.

### Add users

In the **Users** tab, click `Add user to app...`, enter the user's email address, and optionally their first and last name.

### Remove users

Click the **Guest** dropdown next to a user and select `Remove`. This removes the user's access to the app.

## Key features

- **User-specific data** — Logged-in user records are automatically available in your [workflows](/zite/workflows)
- **Automatic security** — Backend workflows are secured by default for authenticated users
- **No user limits** — Add unlimited users without per-seat pricing
- **Database integration** — Connect to Airtable, Google Sheets, Zite Database, or other databases

<Info>
  To automatically sync user data to a database table, see [User sync](/zite/access/user-sync).
</Info>
