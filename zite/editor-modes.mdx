## Overview

Creating an app involves more than just building. It also includes planning and asking questions. Zite has three editor modes. All three consume credits, but Plan and Chat modes use fewer. Choosing the right mode for each task will help you work more efficiently and avoid accidental changes.

## Pick the right mode

| Mode           | Best for                              | Makes changes?        |
| -------------- | ------------------------------------- | --------------------- |
| **Build mode** | Actively developing your app          | ✅ Yes                 |
| **Plan mode**  | Scoping and clarifying requirements   | ❌ No (creates a plan) |
| **Chat mode**  | Asking questions, getting suggestions | ❌ No                  |

<Tip>
  For big projects or uncertain requirements, start in Plan mode. It helps you plan carefully before building and often uses fewer credits overall, similar to Chat mode.
</Tip>

## How to switch modes

On the Zite app editor, click the `Mode` on the lower left followed by your preferred mode.

Alternatively, you can press `Shift` + `Tab` or `Cmd/Ctrl` + `. `on your keyboard.

## Creating a new app

When you create a new Zite, you’ll see two options:

- **Build it**: Start building immediately
- **Plan it**: Create a plan first, then build it

  src="/images/Screenshot2026-01-09at3.37.30PM-1.png"
  alt="Screenshot2026 01 09at3 37 30PM 1"
  style={{ width:"83%" }}
/>

The same shortcuts (`Shift` + `Tab`, `Cmd/Ctrl` + `.`) work on the initial creation screen too.
